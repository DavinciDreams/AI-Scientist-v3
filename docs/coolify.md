# Coolify with Z.ai GLM-5.3-Flash

This deployment serves the existing Run Inspector and provides `agsci-zai` in
the container terminal to launch research runs. The inspector browses results;
it does not launch jobs. Starting/restarting the service does not start research.

The pipeline retains the upstream Docker architecture: a controller launches
each agent phase in the image built from `src/docker/agent-cli/Dockerfile`.
`provider=zai` selects Pi, `zai/glm-5.3-flash`, and bridge networking. The checked-in
Pi catalog sets the OpenAI Chat Completions coding endpoint explicitly:
`https://api.z.ai/api/coding/paas/v4`. This is distinct from both Z.ai's standard
API and its Responses endpoint. Put a Coding Plan API key in `ZAI_API_KEY`.

References: [upstream installation](install.md),
[Z.ai endpoint documentation](https://docs.z.ai/devpack/tool/others),
[GLM-5.3-Flash](https://docs.z.ai/guides/vlm/glm-5.3-flash),
[Coolify Compose services](https://coolify.io/docs/applications/builds/docker-compose).

## Build on the Coolify destination

The following commands run on the Linux Docker host, from a source checkout.
Use an immutable hexadecimal revision or source archive SHA-256 as `REVISION`:

```sh
REVISION=<commit-or-source-sha256>
docker build --network=host -t "sakanascientist/agent:$REVISION" -f src/docker/agent-cli/Dockerfile .
docker build --network=host --build-arg "SOURCE_REVISION=$REVISION" -t "sakanascientist/controller:$REVISION" -f deploy/coolify/Dockerfile .
mkdir -p /data/sakanascientist
```

The upstream agent image includes TeX Live, Chromium, Draw.io, Autoillustrate,
Headless and the agent CLIs. Its first build downloads several GB. CPU tasks
such as `examples/circpack` need no GPU. GPU presets also need the NVIDIA
container toolkit and explicit GPU configuration; this stack defaults to CPU.

## Create the Coolify service

1. Create project `sakanascientist`, production environment, on the host where
   both images were built. Choose **Docker Compose** and paste
   `deploy/coolify/compose.yaml`. This is a prebuilt-image service, so it does
   not need a Git checkout in Coolify or a Compose `build: .` context.
2. Set runtime environment variables:
   - `SAKANA_IMAGE=sakanascientist/controller:<revision>`
   - `AGENT_IMAGE=sakanascientist/agent:<revision>`
   - `ZAI_API_KEY=<Coding Plan key>`
   - `INSPECTOR_USERNAME=lisa` (or your preferred username)
   - `SERVICE_PASSWORD_64_INSPECTOR` is generated by Coolify. Keep it private.
3. Set the scientist service domain to
   `https://sakanascientist.flobots.xyz:8765` (or your chosen hostname), and
   ensure DNS/tunnel routing reaches this Coolify proxy. The `:8765` suffix
   selects the internal port; public HTTPS uses port 443.
4. Deploy. `/api/healthz` is public and returns only health status. The frontend,
   API, assets, and refresh action require HTTP Basic authentication. Retrieve
   the password from Coolify's environment-variable panel. Use HTTPS.

The controller mounts the host Docker socket and therefore has administrative
Docker access on that host. Use this service for trusted tasks under owner
control. Agent containers do not receive the socket by default. Do not set
`AGENT_CONTAINER_MOUNT_DOCKER_SOCK=1` for ordinary runs.

`/data/sakanascientist` is a persistent host bind mount at the **same absolute
path** inside the controller. This is essential: the host daemon resolves the
pipeline's bind-mount sources on the host filesystem. It holds immutable source
releases, results, task uploads, scratch space and a mode-0600 provider env file.
The private controller home also persists sandbox recovery records and caches.
Only the Z.ai provider key is forwarded to the selected agent. Keep backups of
results/tasks, protect the host data directory, and exclude `secrets/` from
exports. Redeployment selects a new source release and retains existing results.
The two narrow IPC mounts preserve the upstream evaluator and task-repair Unix
socket paths across the controller and agent containers. They are private to UID 0.

## Check and run

Open the scientist container terminal in Coolify:

```sh
agsci-zai doctor examples/circpack
agsci-zai run examples/circpack --dry-run
agsci-zai run examples/circpack \
  investigation.execution.max_idea_cycles=2 \
  ablations.execution.num_replications=1 \
  ablations.execution.max_evals_per_variant=2 \
  posthoc.execution.max_selected_analyses=1
```

For long jobs, use a persistent terminal or a Coolify scheduled task. Refresh
the inspector after results appear. Place your own tasks under
`/data/sakanascientist/tasks` and pass their absolute paths.

Z.ai Flash supports image input but does not generate bitmap images. Optional
concept-image generation and the external OpenAI manuscript reviewer require
their own supported provider/key; a Z.ai key is not an OpenAI credential.
The default phase list excludes the external reviewer. Cost summaries are token
price estimates; they do not measure Coding Plan points or subscription charges.

To upgrade, rebuild both images under a new immutable tag, update the two
Coolify image variables, then redeploy. Retain prior tags for rollback. Inline
Compose has no automatic Git deployment; a Git push alone does not update it.
